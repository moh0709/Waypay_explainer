# WayPAY Explainer Static Implementation

This folder contains the improved static HTML explainer implementation.

Files planned in this folder:

- `index.html` — main explainer overview/configurator.
- `explainer.html` — reusable animated explainer template.
- `explainers.json` — explainer data.

The original files in the repository root are not overwritten:

- `waypay-explainer-video.html`
- `waypay-salon-explainer.html`
- `waypay-start-guide.html`

This implementation is designed as a data-driven static HTML system with scene-based animation, visual cards, infographic-style customer journeys, SEO metadata and AEO-friendly question/answer structure.
